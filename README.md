# Netflix Clone

A high-fidelity Netflix UI clone built with React and Tailwind CSS. This application features a cinematic user experience, responsive design, and smart search capabilities.

## Features

- **Cinematic UI**: Authentic Netflix look and feel with high-quality imagery and smooth transitions.
- **Smart Search & Filters**: Enhanced search functionality allowed filtering by genre, year, rating, and cast.
- **Browse Navigation**: Dropdown menu for easy access to various categories and genres.
- **Interactive Movie Modals**: View details, cast, and play trailers directly within the app.
- **Watchlist**: Add and remove movies from your personal "My List" collection.
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile screens.

## Tech Stack

- **Framework**: React 18
- **Styling**: Tailwind CSS
- **Animations**: Motion (framer-motion)
- **Icons**: Lucide React
- **Build Tool**: Vite

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
